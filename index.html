    How this is made

    The table is generated from the vendors' own lists: Apple's System Fonts page for iOS and macOS, the Android Open Source Project's fonts.xml, and Microsoft's Windows 11 font list. Only fonts those lists mark as preinstalled count. Fonts added by device makers, language packs or apps are left out.

    Which script a font covers, what kind of face it is and the stacks above are curated by hand in a sidecar file. Corrections are welcome on GitHub.
